## 🚀 About The Project

**Smart_Shield** is an advanced disaster management system that monitors environmental conditions and provides real-time alerts to prevent disasters like floods.

Built using **Vibe Coding principles**, this project focuses on rapid development, smart tools, and real-world impact.

It integrates **IoT sensors**, **Flask web apps**, and an **AI assistant** to deliver a complete smart safety solution.

## 📡 Hardware Implementation

Smart_Shield is integrated with IoT-based flood monitoring hardware deployed near dams, rivers, and village areas. Water level sensors continuously monitor rising water levels and detect potential flood conditions in real-time.

The hardware unit (Arduino/ESP32) sends live data to the server via Wi-Fi, enabling early warning alerts for nearby villages and authorities. This helps in preventing disasters by allowing timely evacuation and safety measures.

By combining physical sensors with software intelligence, Smart_Shield ensures accurate monitoring of critical zones and enhances disaster preparedness in flood-prone regions.

## ⚙️ How It Works


Sensor → WiFi → Flask Server → Dashboard → Alerts → User



Smart_Shield operates through a seamless integration of hardware sensors, backend processing, and user interface:

1️⃣ 🌊 **Water Level Detection**
Water level sensors placed near dams, rivers, and village areas continuously monitor the rise in water levels.

2️⃣ 📡 **Data Transmission**
The sensor data is collected by a microcontroller (Arduino/ESP32) and sent to the server via Wi-Fi using HTTP requests.

3️⃣ 🧠 **Backend Processing**
The Flask backend receives the data, processes it, and compares it with predefined safety thresholds.

4️⃣ 📊 **Real-Time Dashboard Update**
The processed data is displayed on a web dashboard with live updates and visual representation.

5️⃣ 🚨 **Alert Generation**
If the water level crosses the safe limit, the system automatically triggers alerts and notifications.

6️⃣ 🤖 **AI Assistance**
An integrated AI assistant provides emergency guidance, safety measures, and first-aid instructions to users.
